# PLauncher

A simple Windows launcher for Prison Life's normal and voice chat servers.

Requires Windows 10/11, .NET Framework 4.8 or later, and Roblox installed and signed in.

## How it works

The program launches `roblox://placeId=155615604` through Windows. It reads local Roblox Player logs to recognize Prison Life.

There is no injected code.
